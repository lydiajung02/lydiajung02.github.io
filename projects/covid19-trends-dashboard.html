COVID-19 Trends Dashboard

An interactive dashboard that turns raw daily case counts into a smoothed, comparable trend line across countries — rolling averages and growth rate, not just cumulative totals.

Live Demo

How Did I Do This?

  1. 1. Data ingestion Pulled daily case/death counts per country from a public time-series source and loaded into pandas with a proper date index, one row per country per day.
  2. 2. Cleaning Raw daily counts are noisy: reporting agencies issue backdated corrections that occasionally show up as negative "new cases." I clipped negatives and reallocated large corrections backward across the affected window instead of letting them spike a single day.
  3. 3. Feature engineering Computed a 7-day rolling average per country to remove weekday reporting artifacts (e.g. low weekend counts), and a day-over-day growth rate to flag acceleration/deceleration independent of population size.
  4. 4. Visualization decisions Chose linear scale with rolling averages as the default view — log scale is more "correct" for exponential growth but is harder for a non-technical audience to read at a glance, so I kept it as a secondary toggle rather than the default.
  5. 5. Shipping it The production version runs the aggregation in a scheduled Python job and serves static JSON that this page's chart reads client-side — no server needed to keep it live.
